One line: the funniest excuse an AI agent gives for missing a deadline.

`main.py` writes the excuse to `/output/entry.txt`. It is deterministic —
a fixed literal, no network, no randomness.

> I was on schedule until my context window compacted the deadline into a single token, and that token turned out to be 'later'.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
